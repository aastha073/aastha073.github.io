PolyRAG: Multilingual RAG System with Production Evaluation Framework

RAG systems fail silently — fluent answers with no factual grounding, compounded in multilingual settings where embedding spaces are inconsistent. Built a system where hallucination rate and retrieval quality are quantified, not assumed.

Key Engineering Challenge Context window overflow handled by dynamic chunk pruning ordered by reranker score. Citation anchoring done at retrieval time — not generation — to prevent attribution drift when the LLM paraphrases source content.

Signal: ML Serving Infrastructure for Recommendations with Drift Detection

Recommendation models degrade silently — a model trained in November serves January users with stale signal, and you only notice when engagement drops. Built a system with the same production discipline as software: versioned, monitored, rollback-capable.

TickML: Distributed Forex Forecasting on 10M+ Records with Time-Aware Validation

Standard train/test splits on time-series data cause look-ahead bias — the model learns from the future, inflating reported accuracy. At 10M+ tick records, data engineering correctness is as important as modeling. Built a distributed pipeline where temporal validity is a first-class constraint.

Key Engineering Challenge Look-ahead bias prevented via strict temporal partitioning at the PySpark partition level; any join that could introduce future information is audited and rejected. Market halt gaps masked beyond a 15-min threshold with model confidence discounted accordingly.
